# Virtual Map of Centennial High School
This repository contains the code to Centennial High School's Online Map.

## How Do I Edit in GitHub?
It is possible to update the code yourself in the chsmap.github.io repository. You will see the changes instantly after committing. You don't need to utilize an IDE, you can change the code directly on GitHub.

## How Do I Update Room Numbers/Teacher Room Locations?
For any future room number/teacher room changes:
1. Locate the **index.html** file in the **chsmap.github.io repository**.
2. Click on the pencil icon/button to edit.
3. Change the room numbers located in the quotation marks of **`data-name=" "`**.
4. To edit teacher names, change last names in the quotation marks of **`data-teacher=" "`**.
5. When finished, click "Commit Changes" to publish edits.

> [!NOTE]
> Each room or street code starts with `<map-room>` and ends with `</map-room>`or `<map-street>` and ends with `</map-street>`.
